# Pages.devmode

### Hotkey to edit GitHub Pages instantly

Make editing your GitHub Pages easier. Press the dot key twice to edit the GitHub Pages site. Press “css” to edit the CSS file.

Installation<br>
1. Please embed the JavaScript into any part of your GitHub Pages site.
2. Specify the variables within the script.

----

### GitHubページからホットキーで即編集

あなたのGitHub Pagesの編集を簡単にします。ドットキーを2回押すと今見ているGitHub Pagesの記事を編集します。cssと押すとcssファイルを編集します。

インストール方法<br>
1. Javascrptをお使いのGitHub Pagesのどこかに組み込んでください。
2. スクリプト内の変数を指定してください。
